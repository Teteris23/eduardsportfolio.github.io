Figma AI Design Assistant

AI-assisted UI/UX design inside Figma

Developed a Figma plugin that uses Anthropic’s Claude API to automate design tasks. It restyles selected frames without changing the originals, builds reusable component and colour libraries, and generates screens and connected user journeys from text descriptions.

Built with TypeScript and a local Node.js/Express backend that keeps the API key on the server. Created as a bachelor’s thesis prototype at Riga Technical University.
